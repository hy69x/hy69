

\# 3D Train Journey Portfolio



An interactive 3D portfolio website built using JavaScript, Three.js and Vite. The project presents portfolio sections through an immersive train journey experience.



\## Features



\- Interactive 3D environment powered by Three.js

\- Train journey portfolio experience

\- Camera and zoom configuration

\- Custom lighting and atmospheric effects

\- Portfolio sections:

&#x20; - Loco

&#x20; - About

&#x20; - Skills

&#x20; - Projects

&#x20; - Interests

&#x20; - Contact



\## Technologies Used



\- JavaScript

\- Three.js

\- GSAP

\- Simplex Noise

\- HTML5

\- CSS3

\- Vite



\## Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/hy69x/hy69.git

&#x20;  ```



2\. Navigate to the project directory:



&#x20;  ```bash

&#x20;  cd hy69

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



\## Running Locally



Start the development server:



```bash

npm run dev

```



Open the local URL displayed in your terminal.



\## Available Commands



| Command | Description |

|---|---|

| npm run dev | Start development server |

| npm run build | Build production files |

| npm run preview | Preview production build |
